API Endpoint Anatomy

The four files behind any endpoint, the CRUD route table, and the commands that tell you the truth about a codebase you did not write.

Companion to Lesson 2 · designed to print

1Reading order for any endpoint

#Open thisTo answer
1routes/api.phpWhich controller + which middleware guard it
2app/Http/Controllers/XController.phpWhat happens on the request
3app/Models/X.phpFields, $fillable, relationships, scopes
4app/Http/Resources/XResource.phpWhich fields become JSON
Never skip step 1

A controller shows you what an endpoint does, never who is allowed to do it. Authentication, authorization, and tenant scoping are applied at the route. Reading the controller alone will give you a confidently wrong picture of an endpoint's security.

2Routes generated by apiResource

Route::apiResource('halaqas', HalaqaController::class) registers five routes. Route::resource registers those five plus create and edit, which exist only to serve HTML forms (docs).

VerbURIMethodRoute name
GET/halaqasindexhalaqas.index
POST/halaqasstorehalaqas.store
GET/halaqas/{halaqa}showhalaqas.show
PUT/PATCH/halaqas/{halaqa}updatehalaqas.update
DELETE/halaqas/{halaqa}destroyhalaqas.destroy

Narrow the set explicitly when an endpoint should not exist:

Route::apiResource('halaqas', HalaqaController::class)->only(['index', 'show']);
Route::apiResource('halaqas', HalaqaController::class)->except(['destroy']);

3Route model binding

A type-hinted Eloquent parameter whose name matches the URI segment is resolved from the database automatically. No match means an automatic 404, and the method body never runs (docs).

// Route
Route::get('/halaqas/{halaqa}', [HalaqaController::class, 'show']);

// Controller — $halaqa arrives already loaded
public function show(Halaqa $halaqa)
{
    return new HalaqaResource($halaqa);
}
VariantEffect
{halaqa} + Halaqa $halaqaLooks up by primary key (id)
{halaqa:slug}Looks up by the slug column instead
->withTrashed()Also resolves soft-deleted rows
Name mismatchNo binding. You receive a raw string, not a model
The failure mode worth memorising

If the variable name and the URI segment disagree — {halaqa} with Halaqa $circle — binding silently does not happen and you get the raw URL value. When a controller mysteriously receives a string where a model was expected, check this first.

4API Resources — the JSON contract

class HalaqaResource extends JsonResource
{
    public function toArray(Request $request): array
    {
        return [
            'id'   => $this->id,
            'name' => $this->name,
        ];
    }
}
Returning from a controllerProduces
new HalaqaResource($halaqa)One object, wrapped in data
HalaqaResource::collection($halaqas)An array, wrapped in data

The outermost resource is wrapped in a data key by default. A global JsonResource::withoutWrapping() call in a service provider removes it (docs) — check there before assuming an unwrapped API is doing something exotic.

5Commands that tell you the truth

CommandAnswers
php artisan route:listEvery real route, expanded
php artisan route:list --path=halaqaJust the ones matching a path
php artisan route:list --except-vendorHides package routes — much shorter
php artisan --versionThe framework version you must read docs for
php artisan make:controller XController --apiGenerates a controller minus create/edit
php artisan make:resource XResourceGenerates a JSON resource class
The habit

route:list is your console.log for routing. URLs are generated by apiResource, so they cannot be found by searching the codebase for the URL string. Reach for this command before you reach for the search box.
